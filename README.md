   - **Quiz: "How Well Do You Know Pankaj & Pooja?"**: Heartwarming multi-choice couple trivia with instant feedback and score certificates.

## 🚀 How to Run the Website

### Option 1: Direct Open (Simplest)
Just double-click `index.html` to open it in Google Chrome, Microsoft Edge, Safari, or Firefox.

### Option 2: Run a Local Server
In this folder, open PowerShell or Terminal and run:
```bash
python -m http.server 8000
```
Then open your browser at:
```
http://localhost:8000
```
